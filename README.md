# 일산 고교 선택 도와드려요!

5A 수학학원의 고양시(일산서구·일산동구·덕양구, 파주 운정고 포함) 고등학교 32곳의 공시 데이터를 학생 조건에 맞춰 여섯 관점(내신 경쟁력·면학 분위기·대학 진학·희망 계열 적합·통학·교육 여건)과 **수학 관점**(수학 교과 편제·수학 경쟁력)으로 비교하는 **정적 웹 도구**입니다. AI·서버·DB가 없고, 모든 계산은 브라우저 안에서만 실행됩니다(외부 요청은 결과 화면의 네이버 지도뿐 — 공개 Client ID만 쓰며 허용 도메인으로 제한).

운영자 요청으로 경기영상과학고·고양예술고·고양일고·신원고·신일비즈니스고·일산고·일산국제컨벤션고 7개 학교는 비교 대상에서 뺐다(`schools.json`·`reviews.json`에서 제거, `scripts/build-data.mjs`의 `EXCLUDED_IDS`로 재생성 시에도 제외).

기능: **학교 추천** (`#finder`) — 입력 → 후보 선정 → 점수 → 순위·근거 표시 (한 페이지, 화면 전환 없음)

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # tsc + vite build → dist/ (정적 산출물)
npm run preview  # dist/ 미리 보기
```

## 보충 공시 반영 (supplement/)

- 중점·특색 지정(과학중점 정발고·일산동고·주엽고, AI 중점 백마고, AI 융합학급·IB 후보 일산대진고, 자공고 2.0 백석고·운정고): 희망 계열이 맞을 때 계열 적합 +8(과학중점×이공계) / +6(AI×IT·공학). 카드 배지와 상세 '지정·운영'에 근거 문서 제목 표시.
- 자율학교 지정·운영 O/X(학교알리미 공시 표)가 기존 2차 자료 값을 대체.
- 2025학년도 학업중단율(32개 학교): 교육 여건의 15% 보조 신호, 성취도 없는 학교의 면학 분위기 추정에 10% 보조 신호. 상세에 학년별 수치 표시.
- 2027 배정 규칙: 고양 평준화(1구역 덕양구 / 2구역 일산동·서구, 1단계 학군내배정 5지망 추첨 → 2단계 구역내배정, 향동고 학군내배정만). 기본 후보는 지망 가능 구역의 일반고만, 거주 학군 밖 평준화 일반고는 ×0.75 + 배지. 특목·특성화는 '학교별 전형', 운정고는 '파주 비평준화 자체 전형(내신 200점, 360명)'로 표시.
- 성취도(A~E)는 보충 조사에서도 추가 확보되지 않았다(나머지 학교 CAPTCHA). 운정고 1개 학교 그대로.

## 데이터 한계 (화면에도 표시됨)

- 과목별 성취도(A~E)는 32개 학교 중 **운정고 1개 학교**만 확보. 나머지 학교의 '면학 분위기'는 졸업생 진학 지표로 **추정**(화면에 '추정' 표시), '강점·약점 과목 궁합'은 중립(50).
- 특성화고(고양고)는 졸업생 진로 공시가 없어 '대학 진학'을 중립(50)으로 둠.
- 중점·특색 지정은 학교알리미 공시 문서 제목·학교 공지 기준(지정 통지서 본문 미열람). 2027 단계별 배정 비율은 공식 발표에 없어 표시하지 않음.
- 운정고(파주시)는 관심 학교로 추가했을 때만 후보에 들어가며 파주 비평준화 자체 전형으로 표시.

## 내신 입력·지도·수학 지표·학교별 리뷰

- **내신 입력(기본)**: 내신 총점(200점 만점) + 과목별 성취도(국·수·영·사·과 A~E, 아는 과목만). 200점 = 교과활동 150 + 출결 20 + 봉사활동 20 + 학교활동 10 (경기도교육청 「고등학교 입학 내신성적 반영지침」 2026·2027학년도; 고양 등 9개 평준화학군은 이 점수로 배정예정자를 선발한 뒤 선지원·후추첨). 총점은 지침 산식(일반교과 학기별 기본점수 + 성취도 평균 + 원점수 평균, 체육·예술 30점)에 비교과 만점·원점수 구간 중간값(A 95·B 85…)·체육예술 같은 수준을 가정해 성취도 평균(A=5…E=1)으로 되돌린다: 총점 ≈ 121.3 + 15.3 × 성취도 평균. 고른 과목 평균과 같은 비중으로 합친 뒤 성적대 대표값(상위 4·11·28·55·82%) 사이를 선형 보간해 내부 추정 위치를 만들고, 그 위치가 속한 성적대(5·15·40·70% 경계)로 선발형 도전 여부·분석 비중을 정한다 (`src/engine/standing.ts`). **화면에는 정밀한 '상위 X%'를 보여 주지 않는다** — 중학교·지역마다 성취도 분포와 내신 산출이 달라 같은 점수라도 위치가 다르므로, `standingRange()`가 성취도 평균 ±0.25 안에서 걸치는 성적대를 묶어 '대략적 위치: 상위~중상위권 (대략 상위 5~40%)'처럼 구간으로만 표시하고 '참고용 대략 추정 · 중학교·지역에 따라 달라짐'(`STANDING_NOTE`)을 붙인다(입력 칸·결과 배지·점수 근거 공통).
- **희망 계열·학과(여러 개 선택)**: 입력 폼 6번의 계열 칩을 여러 개 켜고 끈다(다시 누르면 해제, ‘아직 모름’ = 모두 해제, `Profile.tracks: string[]`). 계열 적합 = 고른 계열마다 2026학년도 1·2학년 시간표의 핵심 과목 개설 비율을 구해 **같은 비중으로 평균**(15~95점, 과목 목록이 긴 계열이 결과를 좌우하지 않게) + 학교 운영 가산(교과교실제·수준별 수업·자율학교) + 고른 계열 중 하나라도 맞으면 과학중점(+8)·AI 중점(+6)·외고/국제고(+30)·특성화고(±40) 가감(`trackFit`, `src/engine/score.ts`). 개설·미확인 과목 목록은 계열끼리 겹치는 과목을 한 번만 보여 주고, 점수 근거에 계열별 개설 수를 함께 적는다. 아무것도 고르지 않으면 예전 ‘아직 모름’과 같다(계열 적합 비중 ×0.35). 결과 배지 등 화면 표시(`tracksLabel`)는 ‘공학, 의약·보건’처럼 쉼표로 잇는다.
- **간단히 선택하기(보조)**: '점수를 몰라요'를 켜면 기존 5단계 성적대로 고른다(성적대 대표값 그대로 사용).
- **지도**: 네이버 지도 JS API v3(Web Dynamic Map, `src/components/MiniMap.tsx` + 로더 `src/lib/naverMaps.ts`, 결과 화면에서 스크립트까지 지연 로드). 공개 Client ID(`ncpKeyId`)만 쓰며 NCP 콘솔 Maps 애플리케이션의 Web 서비스 URL(`https://hdhhhdhh.github.io`, `http://localhost`)에서만 인증된다 — 로컬 확인은 포트 없는 `http://localhost`(80번)로. Client Secret은 서버 전용이라 저장소·번들에 두지 않는다. 32개 학교를 추천 상위 3(주황)·후보(네이비)·후보 외(회색)로 표시하고, 사는 동 중심에 집 모양 '집' 표시를 둔다(동을 모르면 '기준'). 스크립트를 못 불러오거나 인증에 실패하면 좌표로 그린 위치 개요도로 대신 보여 준다. 동 선택·학교 선택(마커 클릭 포함)·직선거리·카카오맵 길찾기(`https://map.kakao.com/link/to/학교명,위도,경도`, 목적지만 지정 가능)·네이버 지도 검색 링크를 제공한다. 실제 경로·소요 시간은 카카오맵에서 확인한다.
- **수학 경쟁력**은 실제 수학 학력이 아니라 선택·심화 **과목 개설 폭의 추정**입니다. 2026학년도 1·2학년 시간표를 정제한 뒤 미적분 / 기하 / 확률과 통계 / 고급·심화 수학 / 고급 대수 / 인공지능 수학 / 수학과제 탐구 / 경제 수학의 8개 과목군을 동일 비중으로 셉니다. 점수 = 확인된 과목군 수 ÷ 8 × 100 (반올림). 공통수학·기본 대수는 공통 과정이라 가산하지 않으며, 동일 군의 과목·분반은 중복 가산하지 않습니다. 미확인은 미개설 확정이 아닙니다. 대학 진학률을 수학 성적으로 대체하지 않으며 추천 총점에는 넣지 않습니다. 수학 학업성취도는 별도 슬롯에 확보 자료만 표시하고, 없는 학교는 **수집 예정**으로 표시합니다(현재 운정고만 확보).
- **수학 교과 편제**: 학교별 2026학년도 1·2학년(2022 개정) 시간표만 사용하며, 2학년 수학 편제에서 진로·융합·심화 선택 과목을 강조한다(`mathCurriculum`, `src/engine/derive.ts`). 과목 데이터 생성 시에도 이 학년만 남긴다. 학년별 학생 수·졸업생 진로·성취도 공시는 그대로 유지한다. 결과 화면 상단에 '후보 중 수학 선택·심화 과목이 넓은 학교' 상위 3곳을 보여 준다.
- **학교별 리뷰**는 `src/data/reviews.json`(195건, 공개 게시글 발췌 + 원문 URL)을 홈 화면 '학교별 리뷰 모아보기'(`#reviews`)와 각 학교 카드의 '학교별 리뷰'에 수학·비수학 탭으로 표시한다(`ReviewList.tsx`). 형식: `{ "schoolId", "category": "수학"|"비수학", "source", "date", "text": "제목 — 본문", "url" }`. 추천 점수에는 반영하지 않는다('학부모 후기'는 학원 후기로 읽힐 수 있어 '학교별 리뷰'로 부른다). 과외·학원·컨설팅 광고, 모집·구인·기업정보 글, 이름만 같은 다른 지역 학교 글 73건은 뺐다 — `src/data/reviews-excluded.json`(학교 id + 제목 + 사유)에 남기고 `src/data/index.ts`가 이 목록과 모집·구인 문구로 다시 거르므로 reviews.json을 새로 만들어도 돌아오지 않는다. '원문 보기'는 특정 글로 바로 가는 주소일 때만 보인다 — 네이버 카페 첫 화면(글 번호 없음)·SNS 페이지 첫 화면·게시판 목록·태그 검색·사이트 첫 화면 주소는 링크를 숨긴다(`src/lib/reviewLink.ts`).

## 수학 관점 콘텐츠

- **왜 고교 선택에 ‘수학’이 핵심인가** (`MathWhy.tsx`, 홈 상단 `#why-math`): 세 가지 근거를 짧게 보여 준다. ① 학교마다 배울 수 있는 수학이 다름 — 고양 일반고·자공고의 2026학년도 1·2학년 시간표에서 확인된 선택·심화 수학 과목군 수 범위와 인공지능 수학·경제 수학·수학과제 탐구 확인 학교 수를 `schools.json`에서 바로 계산(데이터가 바뀌면 숫자도 바뀐다). ② 대입에서 수학 비중(2028 수능 수학 범위, 서울대·연세대 기하·미적분Ⅱ 권장, 연세대 상경계열 2027 정시 수학 25%→33.3%). ③ 내신 수학의 변별력(2024년 고1 1학기 전국 일반고 수학 A 비율 17.2% < 국어 19.7%·영어 20.6%, 5등급제 1등급 = 상위 10%).
- **고교학점제 수학 과목 선택 가이드** (`MathCourseGuide.tsx` + `src/data/mathGuide.ts`, `#math-guide`): 2022 개정 수학 과목 체계(공통·일반선택·진로선택·융합선택, 과학계열 과목은 각주) → 이과·상경·인문 탭별 과목 순서(기본/권장/선택 칩)와 대학 권장 사례 → 계열과 관계없이 확인할 네 가지(3개년 편제표, 실제 개설 여부, 학교에 없을 때 공동교육과정·고양공유학교 학점인정형, 지원 학년도 기준). 특정 학교를 추천하지 않는 일반 안내이며 학교별 편제는 결과 카드의 '5A 수학 관점'에서 본다.
- **성취도 비율·지표 ≠ 학교 실력** (`IndicatorNote.tsx`): 성취도 A 비율·수학 경쟁력·추천 점수가 보이는 곳(결과의 '읽기 전에 꼭 확인하세요', 수학 관점 한눈에, 비교표, 각 학교 카드의 점수 막대·수학 관점·성취도 표, '어떻게 분석하나요?' 7번)에 같은 문장을 붙인다.
- **출처 표기** (`src/data/references.ts`, `SourceLinks.tsx`): 외부 자료의 사실·수치는 원문을 직접 확인한 글만 `REFS`에 두고, 문장 끝에 원문 링크(`Cite`/`Cites`), '어떻게 분석하나요?' 아래에 전체 목록(`SourceList`)을 단다. 기사는 운영자가 제공한 자료실(교육을 비추다 입시 지식서재 · 퀴트린 지식서재)에서 찾았고, 인용은 원문(kyobit.com 기사, 퀴트린 네이버 블로그)으로 한다. 과목 체계는 경기고교학점제 지원센터 안내로 확인했다.
